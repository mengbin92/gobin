# Gobin 文档目录

本文档目录按用途分为以下子目录：

| 子目录 | 内容 | 典型读者 |
|--------|------|----------|
| [`releases/`](./releases/) | 版本发布说明（RELEASE-NOTES）与更新日志（CHANGELOG），以及跨平台构建和发布指南 | 所有用户 / 发布维护者 |
| [`guides/`](./guides/) | 面向使用者的功能使用指南（短代码、增量构建、并行构建、日志、资源管线、serve、图片优化、Jekyll 迁移） | 站点作者 / CI 维护者 / 主题作者 |
| [`design/`](./design/) | 功能设计文档（specs），说明"为什么这样设计、边界在哪" | 贡献者 / 维护者 |
| [`plans/`](./plans/) | 实施计划（plans），包含优化排期、重构计划与功能实施步骤 | 贡献者 / 维护者 |
| [`reports/`](./reports/) | 测试覆盖报告、阶段完成总结等阶段性报告 | 贡献者 / 维护者 |
