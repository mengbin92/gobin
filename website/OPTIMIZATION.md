## 🎯 建议的后续优化

### 高优先级

#### 1. 添加 404 页面
创建 `website/_posts/404.md`：

```markdown
---
title: "404 - Page Not Found"
date: 2024-01-01
draft: false
---

# 404 - Page Not Found

The page you are looking for doesn't exist.

[Go Home](/)
```

#### 2. 添加 robots.txt
在 `website/assets/robots.txt`：

```
User-agent: *
Allow: /
Sitemap: https://gobin.dev/sitemap.xml
```

#### 3. 优化字体加载
考虑使用 `font-display: swap` 减少字体阻塞：

```css
@font-face {
  font-family: 'JetBrains Mono';
  font-display: swap;
}
```

或使用 Google Fonts 的 `display=swap` 参数。

#### 4. 添加预加载关键资源
在 HTML head 中添加：

```html
<link rel="preload" href="/css/theme.css" as="style">
<link rel="preload" href="/js/theme.js" as="script">
```

### 中优先级

#### 5. 添加面包屑导航
为内页（文档、配置等）添加面包屑导航，提升 SEO。

#### 6. 改进代码示例展示
使用更现代的代码块设计，添加"复制"按钮。

#### 7. 添加页面过渡动画
页面切换时添加淡入淡出效果，提升体验。

#### 8. 添加加载状态
为外部资源（字体、图片）添加加载指示器。

### 低优先级

#### 9. 深色模式自动切换
根据系统偏好自动选择深色/浅色模式。

#### 10. 添加搜索功能
使用已生成的 search-index.json 实现前端搜索。

#### 11. 添加评论系统
为文档页面添加评论（Utterances/Giscus）。

#### 12. 添加页面视图统计
使用简单的 analytics 或 Plausible（隐私友好）。
